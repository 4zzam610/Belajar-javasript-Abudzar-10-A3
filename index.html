Project Submission Javascript (Pertemuan 1 - 7)

Petunjuk Pengerjaan:

  1. Buka file script.js di code editor kamu.
  2. Tuliskan kode jawaban pada baris kosong di bawah masing-masing komentar soal cerita.
  3. Buka halaman ini di browser, lalu tekan F12 (atau klik kanan > Inspect > pilih tab Console) untuk melihat hasil eksekusi jawabanmu.
  4. Pastikan semua soal terjawab dari Bagian 1 sampai Bagian 7.

Semua soal cerita dan studi kasus dirancang berdasarkan materi yang telah dipelajari dari Pertemuan 1 sampai Pertemuan 7.
